# Banking Loan Analytics Dashboard | Tableau

**Interactive Business Intelligence & Portfolio Analysis**

## 1. Project Overview

This project focuses on analysing banking loan data through an interactive Tableau dashboard. It examines loan funding, portfolio distribution, interest generation, and delinquency and default indicators.

The objective is to convert structured banking data into actionable visual insights that support business analysis and loan portfolio monitoring.

## 2. Business Objectives

- Evaluate overall loan funding and portfolio size.
- Analyse loan distribution across geographical and borrower categories.
- Examine monthly loan funding trends.
- Monitor delinquency and default indicators.
- Identify patterns relevant to lending performance and portfolio risk.

## 3. Key Performance Indicators

| KPI | Analytical Purpose |
|---|---|
| Total Loan Amount Funded | Measures overall loan funding |
| Total Loan Count | Tracks the number of loans |
| Total Interest | Measures interest generated |
| Delinquent Loan Count | Monitors delinquent loans |
| Default Loan Rate | Measures the proportion of default loans |

## 4. Dashboard Analysis

The dashboard presents four analytical visualizations:

- **State-wise Loan Funding:** Compares loan funding across states.
- **Grade-wise Loan Funding:** Examines funding distribution across loan grades.
- **Monthly Loan Funding Trend:** Tracks loan funding over time.
- **Religion-wise Loan Distribution:** Analyses loan distribution across borrower categories.

Interactive filters enable users to explore the data by state and religion.
